# Link Checker for Markdown Files

## Описание
Консольное приложение для проверки ссылок (`http://`, `https://` и `file://`) в `.md` файлах.

`file://` ссылки поддерживаются как с абсолютными путями (`file:///path/to/file`), так и с относительными (`file://./relative.md`, `file://../parent.md`) — относительные разрешаются относительно папки `.md` файла, в котором найдена ссылка.

## Установка
### Через Python
Зависимостей нет, нужна только стандартная библиотека Python 3.8+ (macOS).

```bash
python3 main.py /path/to/folder
```

### Исполняемый файл
Скачать бинарник для вашей ОС из папки `dist/` или собрать его локально.

## Использование
```bash
python3 main.py /path/to/folder
./link_checker /path/to/folder
```

Опционально:
```bash
python3 main.py /path/to/folder --timeout 1.0 --max-workers 10
```

## Пример вывода
Таблица со статусом, ссылкой и путём к `.md` файлу. Сначала ошибки, затем успешные проверки.

```
Итого: 10 ✅ Успешно: 7 ❌ Ошибок: 3
```

Статистика считается по уникальным ссылкам. Если одна ссылка встречается в нескольких файлах, HTTP/file статус запрашивается один раз.

## Сборка
```bash
pyinstaller --onefile --name link_checker main.py
```

Готовый исполняемый файл будет в папке `dist/`.
