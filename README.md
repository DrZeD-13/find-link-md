# Link Checker for Markdown Files

## 📝 Описание
Это консольное приложение, написанное на Python, предназначено для рекурсивного сканирования всех Markdown-файлов (`.md`) в указанной директории. Его основная задача — извлечь все обнаруженные URL-ссылки (как сетевые `http://`/`https://`, так и локальные `file://`) и проверить их доступность, предоставляя подробный отчет о статусе.

## ⚙️ Назначение и функционал
Приложение выполняет следующие действия:
1. **Сканирование:** Рекурсивно обходит целевую директорию в поисках `.md` файлов.
2. **Извлечение:** Находит все полные ссылки (`[text](url)`) в найденных файлах.
3. **Проверка HTTP/S:** Для сетевых ссылок выполняет GET-запрос с таймаутом 1 секунда, проверяя коды статуса (200-399 - успех, 4xx/5xx - ошибка).
4. **Проверка File://:** Для локальных ссылок проверяет существование файла в файловой системе.
5. **Отчетность:** Генерирует подробный вывод в консоль в виде таблицы, цветовой индикации и сводной статистики.

## 🚀 Как использовать (Требуется Python)
### Предварительные требования:
*   Python 3.8+
*   Библиотека `requests` (`pip install requests` или `pip install -r requirements.txt`)

### Запуск:
```bash
python main.py /путь/к/корневой/папке
```

## 📦 Как использовать (Исполняемый файл для macOS)
После сборки в виде бинарника вам не потребуется устанавливать Python. Используйте команду `./link_checker /путь/к/корневой/папке`.

## 🛠️ Сборка исполняемого файла (macOS)
Для создания самодостаточного бинарного файла, который можно запускать без установки Python на Mac:
1. Установите PyInstaller (`pip install pyinstaller`).
2. Выполните команду в терминале из директории с `main.py`:

```bash
pyinstaller --onefile --name link_checker main.py
```

## Запуск на mac os arm64
```bash
./dist/link_checker путь к вашей папке ~/my
```

Готовый исполняемый файл будет находиться в папке `dist/`.

## 🗄️ Структура проекта
*   `main.py`: Основной скрипт анализатора ссылок.
*   `README.md`: Данный файл, описывающий проект и инструкцию по сборке/использованию.
*   `link_checker`: Созданный бинарный файл для macOS (в папке `dist/`).
